# Guia Oficial do Participante — FenaCanto 2026

## Estrutura
- `index.html`: página principal responsiva.
- `docs/dados.js`: conteúdo atualizável da programação, corais, avisos, locais, galerias e contatos.
- `assets/`: logomarca, fotos institucionais e imagem de compartilhamento.
- `docs/fontes-e-pendencias.md`: conferência editorial antes da publicação.

## Atualização rápida
1. Abra `docs/dados.js` em editor de texto.
2. Altere apenas os valores entre aspas, mantendo vírgulas e colchetes.
3. Salve e abra `index.html` no navegador para conferir.
4. Para publicar no Vercel ou GitHub Pages, envie a pasta inteira.

## Antes da publicação
- Trocar `[A CONFIRMAR]` por informações validadas.
- Definir URL final e, se possível, incluir `<link rel="canonical">` no `<head>`.
- Confirmar créditos de realização e apoio.
- Revisar no celular e testar todos os links.
- Atualizar `assets/og-fenacanto-2026.jpg` caso a arte oficial de capa mude.
